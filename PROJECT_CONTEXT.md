# SHOCKIS Medical Website Context

## Project Name

SHOCKIS Medical Website


## Company Background

SHOCKIS is a medical device company focused on professional shockwave therapy systems and related accessories.

The website is designed for global medical device marketing, distributors, clinics, healthcare professionals and OEM partners.


## Main Products

- Shockwave therapy system
- Treatment applicators
- Accessories
- OEM / ODM solutions


## Target Customers

Primary:

- Medical clinics
- Physiotherapy centers
- Rehabilitation professionals
- Sports medicine providers
- Medical device distributors


Secondary:

- OEM partners
- Healthcare organizations


## Website Goals

The website is not only a product showcase.

Future goals:

- Generate distributor leads
- Receive quotation requests
- Provide clinical education content
- Build SEO traffic
- Support global sales


## Technology Stack

Framework:

- Next.js 15
- React
- TypeScript

Styling:

- Tailwind CSS
- Custom CSS components

Database:

- Drizzle ORM
- Cloudflare D1 preparation


## Current Architecture

Main folders:

app/
- pages and website components

public/
- images and static assets

worker/
- backend / Cloudflare related functions

db/
- database related code


## Development Rules

Important:

1. Always keep npm run build successful.

2. Before major changes:
   - check existing structure
   - avoid unnecessary refactoring

3. Preserve SEO structure.

4. Keep medical device wording professional and compliant.

5. Avoid unsupported medical claims.

6. After code changes:
   - run npm run build
   - check Git diff
