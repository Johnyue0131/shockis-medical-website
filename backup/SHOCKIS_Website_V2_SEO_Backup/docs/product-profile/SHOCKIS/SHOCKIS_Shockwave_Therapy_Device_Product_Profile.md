# B. Key Features

1. **Adjustable Output Platform** — 1–8 Bar 压力范围与 1–21 Hz 频率范围，支持 0.1 Bar 压力步进。
2. **Dual Control Workflow** — 7 英寸触摸屏负责快速设置，两枚实体旋钮支持操作中调整。
3. **Seven Interchangeable Treatment Heads** — 七种头部规格用于不同接触面积及身体区域。
4. **Metal Handpiece and Enclosure** — 7000 系列铝合金手柄与金属机身，面向频繁使用场景。
5. **Portable Configuration** — 6 ft（约 1.83 m）线缆与皮革风格提带提升移动便利性。
6. **Operator-Oriented Design** — 实体旋钮可降低触屏沾有耦合剂时的操作不便。
7. **Documentation and Support** — Listing 表示包含快速参考指南、用户手册及技术支持。

# G. FAQ

### 1. What is the SHOCKIS ST100?
